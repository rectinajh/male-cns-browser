# Male CNS Browser

Open-source 3D neuron browser for the Janelia [Male CNS connectome](https://male-cns.janelia.org/).

v0.1 goal: browse a real MaleCNS subset in 3D, inspect key nodes, and play blue “thought” pulses along connectivity paths.
